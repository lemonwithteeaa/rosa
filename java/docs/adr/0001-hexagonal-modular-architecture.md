# ADR 0001: Модульная hexagonal architecture

Статус: принято.

## Контекст

Go-приложение объединяет интерфейс, состояние, хранение и бизнес-правила в одном
пакете. Построчный перенос этой структуры в Java закрепил бы существующую связанность
и усложнил бы доказательство совместимости.

## Решение

Java-версия строится вокруг чистой доменной модели и application use cases. Внешние
системы подключаются через интерфейсы-порты. JavaFX, SQLite, форматы Go и Windows API
реализуются адаптерами. Создание объектов выполняется только в `rosa-launcher`.

Направление зависимостей:

```text
launcher -> ui -> application -> domain
     |         persistence -----> application
     |         compatibility ---> application
     |         platform-windows -> application
     +-------- reports ----------> application
```

Границы проверяются ArchUnit. Новая абстракция добавляется при наличии как минимум
двух реализаций либо при изоляции внешней системы, изменяемого формата или времени.

## Последствия

Расчёты можно тестировать без Windows и JavaFX. Старые данные подключаются отдельным
compatibility adapter. Цена решения — больше модулей и явная сборка зависимостей в
composition root.
