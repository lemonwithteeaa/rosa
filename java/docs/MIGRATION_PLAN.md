# Контролируемая миграция

Каждый вертикальный срез проходит один и тот же шлюз:

1. Зафиксировать вход и результат Go baseline.
2. Добавить контрактный или golden master тест.
3. Реализовать сценарий в domain/application.
4. Подключить адаптер формата или платформы.
5. Выполнить Java unit, integration и architecture tests.
6. Повторно выполнить доступные контрольные тесты Go.
7. Сравнить результаты и данные обеих реализаций.
8. Собрать Windows app image в GitHub Actions.
9. Выполнить ручной smoke test на копии данных.
10. Поставить контрольный тег только после успешной проверки.

При расхождении следующий срез не начинается. Конвертация рабочих данных запрещена
до появления проверенного двустороннего round-trip теста и резервной копии.
