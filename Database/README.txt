Отдельная пользовательская SQLite-база в исходном пакете не обнаружена.

Учебный корпус находится в Source/training_corpus.json и поставляется вместе с реестрами из Training. При запуске программа переносит активные учебные данные в профиль пользователя Windows. Старые синтетические записи выводятся из активных списков; реальные пользовательские записи сохраняются.
