Температурный концентрационный скрининг РОСА.
Источник: USGS PHREEQC 3.8.6-17100, неизменённый database/phreeqc.dat.
Исходный дистрибутив: https://water.usgs.gov/water-resources/software/PHREEQC/phreeqc-3.8.6-17100.tar.gz
Документация PHASES: https://water.usgs.gov/water-resources/software/PHREEQC/documentation/phreeqc3-html/phreeqc3-36.htm
SHA256 phreeqc.dat: 59373961d648dfbf68a40744060c1d64f57ecbec98f4f5fb89f3a1b4213ccd10

Выбранные аналитические коэффициенты вычисляют log K = A1 + A2*T + A3/T + A4*log10(T) + A5/T^2 + A6*T^2; T в кельвинах.
При наличии аналитического выражения оно имеет приоритет над log_k и delta_h. Для гипса используется последнее активное analytical_expression в базе: 93.7 5.99E-3 -4e3 -35.019.
Для кальцита, гипса, барита и целестина эталоны при 0 / 25 / 60 / 90 °C получены запуском неизменённого PHREEQC 3.8.6-17100, собранного из официального исходного дистрибутива. USER_PUNCH вызывает LK_PHASE для этих четырёх фаз при опорном давлении 1 атм. Файл *.pqi содержит вход расчёта, *.tsv — его фактический результат.
Для повторения проверки с установленным PHREEQC: phreeqc phreeqc_temperature_reference.pqi reference.out phreeqc.dat
Результат будет записан в phreeqc_temperature_golden.tsv.

Это проверка температурных констант, а не аттестация всей промысловой модели. В РОСА концентрации используются как свободные, активность воды принята равной 1; комплексообразование, изменение состава по скважине и давление не рассчитываются. Диапазон маршрута РОСА ограничен 0–100 °C без экстраполяции.
PHREEQC создан D.L. Parkhurst и C.A.J. Appelo / USGS; см. USGS_NOTICE.txt. Ядро PHREEQC не включено в исполняемый файл РОСА. В Go реализовано отдельное вычисление четырёх аналитических выражений; оригинальная база не модифицирована.
