ДОПОЛНЕНИЕ RC72
Пять задач фактически выполнены и повторно воспроизведены: прежние две, замкнутые объёмы 0,1/10 л и запас резервуара 1e-8 моль. Все замкнутые задачи имеют баланс C с допуском 1e-12 моль и проверку неизменного объёма. Уменьшение pH при росте объёма проверяется только для этих учебных условий, не как универсальное правило для промысла.
При 1e-8 моль CO₂ запас исчерпан, весь внесённый C в воде, SI газовой фазы -7,291703510017 вместо целевого состояния около -3,5. Этот случай нельзя обозначать как достигнутое равновесие с резервуаром. PR_P/PR_PHI — свойства газовой постановки; при исчерпанном запасе не трактовать их как доказательство достигнутого состояния воды. Проверять водный SI, остаток фазы и материальный баланс вместе.

Внешние эталоны CO₂, RC71
USGS PHREEQC 3.8.9, commit b0b3be767158ccc3322d2c816625cf470045e67e.
Официальная исходная база phreeqc.dat сохранена рядом, SHA-256 в RUN_MANIFEST.json.

Проверка сохранённых файлов: python verify_reference.py
Повторный запуск: python verify_reference.py --engine /полный/путь/phreeqc
Каждая задача запускается в отдельном временном каталоге; отчёты эталона не перезаписываются. Проверяются хеши входов/базы, конечные численные поля с relative 1e-9/absolute 1e-12, баланс общего углерода замкнутой системы <1e-12 моль, сохранение Na/Cl и постоянный объём газа. Это проверки воспроизводимости одинаковой базы, а не точность промыслового прогноза.

В initial_gas.dump записано исходное состояние GAS_PHASE: SAVE gas_phase после реакции намеренно отсутствует. Поэтому -moles является начальным запасом; конечный запас берётся из selected.tsv. Для резервуара проверяются заданное парциальное давление и согласованность SI с log10(P*phi), а не равенство SI и log10(P). В этой базе используется уравнение Пенга—Робинсона. При низком давлении phi близко к 1, но не заменено единицей.

Учебная система содержит только NaCl и CO₂. Изменения pe не интерпретируются как результат промыслового окисления/восстановления. Объём газа 1 л относится только к замкнутой задаче. Ни массы солей, ни эффективности ингибиторов, ни МРП эти задачи не рассчитывают.
