РОСА 7.3.11.586-RC

Продолжение линии 585-RC без редизайна раздела «Методы и мероприятия».

В этой сборке:
- план мероприятий стал управляемым: состояния «Черновик / Выбран / Утверждён / Назначен / Выполнен / Отменён»;
- для каждого метода доступны плановая дата, ответственный, контрольная дата и критерий контроля;
- строка плана связана с сохранённым снимком параметров реализации;
- двойной клик по строке плана открывает редактор исполнения;
- архив решений стал версионным: каждая новая фиксация получает номер версии;
- двойной клик по архивной версии открывает просмотр без изменения текущего состояния;
- восстановление выполняется только после отдельного подтверждения и создаёт новую версию вместо перезаписи старой;
- при восстановлении возвращаются методы/комплекс и сохранённые параметры реализации;
- экран загрузки, приветствие/авторизация, внутренняя шапка и расчётное ядро не изменялись.

Живая проверка Windows обязательна для геометрии окон редактора плана и архива при DPI 100/125/150%.
