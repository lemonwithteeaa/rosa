# Открытые технические источники и решения для инфографики РОСА

Дата: 24.09.2026

## Что следует визуализировать

1. **Историю одного объекта по диагностикам** — отдельная линия для каждого сопоставимого показателя, дата и номер диагностики, изменение к предыдущей точке.
2. **Коррозионный контур** — скорость коррозии, железо, pH, сероводород, углекислый газ и минерализация рядом на одной временной шкале; выбросы отмечать красным, пропуски серым.
3. **Сводку одной диагностики** — карточки «есть данные», «предупреждение», «критическое отклонение», затем компактные горизонтальные полосы по направлениям.
4. **Сравнение объектов** — small multiples с одинаковой шкалой внутри показателя, ранжирование по последнему значению и по изменению.
5. **Эффект режима или ингибитора** — slopegraph/водопад «до → после» с абсолютным и процентным изменением.
6. **Качество данных** — отдельная панель с пропусками, несовместимыми единицами, дубликатами и ошибками валидации.

## Техническое основание

- AMPP/NACE RP0192 описывает железо в пробе как индикатор коррозии и эффективности ингибиторной обработки. Поэтому железо нужно показывать рядом со скоростью коррозии и режимом обработки, а не прятать в общей таблице.
- AMPP/NACE TR31014 указывает на важность периодического и оперативного мониторинга коррозии и раннего обнаружения изменений. Для РОСА это означает обязательный тренд по датам, изменение к предыдущей диагностике и отметку последней точки.
- API RP 51R выделяет необходимость учитывать коррозионную опасность и сероводород в обращении с добываемыми флюидами. В интерфейсе H₂S должен быть самостоятельным показателем риска с единицей измерения и состоянием данных.
- Открытые материалы EPA по контролю качества воды перечисляют pH, температуру, проводимость, сульфиды, жесткость, кальций, железо и другие показатели. Их целесообразно группировать по смыслу: кислотность/окислительно-восстановительные условия, минерализация, коррозионная активность, металлы.
- Работы по visual analytics для многомерных временных рядов рекомендуют связанные представления, small multiples, выделение аномалий и сохранение контекста выбранной точки. Поэтому карточка, тренд, таблица точек и фильтр объекта должны работать как единый экран.

## Приоритет реализации

### Первый экран одной диагностики

- шифр объекта красным жирным;
- дата и источник;
- шесть карточек направлений с количеством заполненных показателей;
- горизонтальные полосы отклонений;
- список проблем качества данных;
- мини-профиль показателей с единицами.

### История объекта

- выбор показателя;
- линия по диагностикам;
- дата, значение, единица, режим;
- изменение к предыдущей точке;
- красная отметка отклонения, серая отметка пропуска;
- предупреждение, если сопоставимых диагностик меньше двух.

### Групповое сравнение

- одинаковая шкала для одного показателя;
- сортировка по последнему значению или изменению;
- отдельная строка «нет данных»;
- раскрытие объекта по щелчку.

## Ограничения

График не должен интерполировать отсутствующие лабораторные значения и не должен смешивать показатели с разными единицами. Отсутствие результата отображается как отсутствие данных, а не как ноль.
