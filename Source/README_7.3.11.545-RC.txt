РОСА 7.3.11.545-RC

Запуск: Windows_x64\РОСА_7.3.11.545-RC.exe

Комплексная инфографика показывает только настоящие линейные зависимости минимум по двум датам. Двойной щелчок по объекту легенды оставляет только его линию. Стрелки ← / → рядом с − / + отменяют и повторяют изменение состава графика.

Перерисовка ускорена: подготовленные серии кэшируются до смены показателя или выбранных данных. Одиночная инфографика сохранена по эталону 502-LAB-LAYOUT без обрезания текста.

Сохранены правильная круглая иконка, фоновый комплексный расчёт и программное присвоение классов осложнений по открытой лабораторной записи.
