# ROSA 7.3.11.800-RC

- Перестроен переход между разделами: прежний экран остаётся видимым, пока целевой обновляет данные и координаты; затем переключается видимость двух страниц и назначается одна перерисовка.
- Разметка каждого раздела рассчитывается по текущему размеру окна перед его показом. Это устраняет открытие ранее не посещённого раздела со стартовыми координатами и необходимость перехода туда-обратно для исправления положения элементов.
- Введена общая транзакция видимости страницы для лаборатории, методов, наработки и экономики. Массовая рассылка `WM_SETREDRAW` по дочерним окнам лаборатории и методов удалена; вложенные обновления завершаются одним согласованием видимости.
- Перемещение элементов во время транзакции не вызывает промежуточной перерисовки. При ошибке переключения предыдущая страница восстанавливается, повторный переход не меняет историю навигации.
- При смене DPI или разрешения программа сохраняет состояние открытого окна. Нормальное окно при необходимости сдвигается в рабочую область; свернутое и развёрнутое не переключаются через Restore/Maximize. Первое открытие остаётся развёрнутым.
- Контрольные проверки охватывают подготовку новой страницы, порядок обновления/разметки/показа, отсутствие массового `WM_SETREDRAW` и сохранение состояния окна.
- Состав учебного набора и расчётных функций из 799-RC сохранён: 20 скважин, 60 отказов, 180 лабораторных паспортов и 180 экономических сценариев.
- Нативная проверка интерфейса на Windows остаётся необходимой: среда сборки компилирует Windows приложение и тесты, но не запускает Win32 GUI.
