# ROSA 7.3.11.793-RC — изменения

- Вместо мигающего слова и кнопки в шапке выводится статичная фраза «В работе учебные примеры».
- Фраза набрана меньшим серым шрифтом, не кликабельна и показывается только в выбранных разделах с учебными данными.
- Удалены мигание, таймер и обработчик клика для этой подписи.
