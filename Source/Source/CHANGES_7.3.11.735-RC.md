# РОСА 7.3.11.735-RC — исправление зависания 7/8 разделов и выгрузки реестра

## Исправлено

- Убрана тяжёлая синхронная миграция подробных учебных отчётов при открытии разделов 7 и 8. Она выполнялась в UI-потоке и могла визуально «замораживать» экран.
- Подробные Sections 1–7 для старых учебных утверждений теперь достраиваются лениво — только при явном открытии или выгрузке конкретного отчёта.
- При выгрузке PDF / WORD / EXCEL сначала сразу открывается стандартное окно выбора пути. Только после выбора файла выполняется достройка подробного снимка. Кнопка поэтому больше не выглядит неработающей.
- Первая утверждённая строка 8 раздела выбирается автоматически после открытия реестра. Выгрузка работает сразу, без обязательного предварительного клика по строке.
- Если строка всё же не выбрана, используется первая запись реестра; если реестр пуст, показывается понятное предупреждение.
- После ленивой достройки подробные Sections учебного отчёта сохраняются обратно в архив: повторное открытие/выгрузка не пересчитывает их заново.

## Сохранено

- Подробная выгрузка разделов 1–7 из 733/734: лаборатория, формулы и подстановки, методы и ограничения, наработка, Benefit Modeling, итоговое решение.
- Отдельные листы Excel по разделам.
- Некликабельные KPI-карточки 8 раздела из RC732.
- Кликабельные карточки 7 раздела.
- Глобальная справка по правому клику на кнопки.

## Технический принцип RC735

Открытие раздела и построение таблицы реестра должно быть дешёвой UI-операцией. Любая тяжёлая генерация подробного отчёта вынесена из пути `switchPage -> refreshArchive` и запускается только по явному действию пользователя.
