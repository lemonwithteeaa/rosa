# РОСА 7.3.11.736-RC — фактическая запись выгрузки 8 раздела

## Исправлено

- Исправлена регрессия, при которой диалог «Сохранить» открывался, но после выбора пути пользователь не получал файл.
- Экспорт PDF / Word / Excel теперь формируется сначала во временный файл, затем проверяется и только после этого переносится в выбранное пользователем место.
- Перед формированием отчёта проверяется реальная возможность записи в выбранную папку.
- После записи проверяется уже конечный файл: наличие, ненулевой размер и структура формата.
- Для DOCX проверяются обязательные части ZIP-пакета Word (`[Content_Types].xml`, `word/document.xml`).
- Для XLSX проверяются обязательные части книги Excel (`[Content_Types].xml`, `xl/workbook.xml`).
- Для PDF проверяется сигнатура `%PDF-` и минимальный размер.
- Успешное сообщение появляется только после подтверждённого существования готового файла в выбранном месте.
- Если атомарная запись через Windows `MoveFileEx` запрещена синхронизируемой/сетевой папкой, используется прямой синхронный fallback с `Flush/Sync`, после чего файл снова валидируется.
- При любой ошибке показывается конкретная причина и выбранный путь; добавлена диагностическая запись этапов START / GENERATE FAIL / COMMIT FAIL / OK.

## Сохранено

- Подробные Sections 1–7 и обогащённые учебные отчёты RC734.
- Ленивое формирование подробного снимка RC735: открытие 7/8 разделов не должно блокироваться тяжёлой генерацией.
- Некликабельные KPI-карточки 8 раздела.
- Кликабельность строк утверждённого реестра и двойной клик по отчёту.
