# ROSA 7.3.11.798-RC

- Ускорена смена разделов: переход скрывает только текущую страницу, обновляет целевую страницу в скрытом состоянии и показывает её после обновления. Удалено повторное перечисление всех дочерних окон и тройной обход полного дерева элементов при каждом переходе.
- Убрана логика, которая блокировала сворачивание по команде Windows и пыталась самовольно восстановить окно. Навигация больше не меняет состояние окна.
- Исправлена миграция лабораторных паспортов: совпадение PassID больше не считается доказательством актуальности. Сверяются объект, дата, источник, паспортные значения, единицы, модель и заключение; старые данные с повторно использованным ID заменяются каноническими.
- Старые записи лаборатории с флагом Deleted больше не попадают в видимую историю.
- Установка DPI-awareness теперь проверяет результат Windows API и включает system-aware fallback при отказе Per-Monitor V2.
- Версия 798 включает корпус 20 скважин, 60 отказов, 180 связанных лабораторных паспортов и 180 экономических сценариев из 797-RC.
- Пересобрано официальным Go 1.27.1 для сравнимого размера бинарного файла с предыдущей сборкой.
