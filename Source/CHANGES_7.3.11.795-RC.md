# ROSA 7.3.11.795-RC — исправление настроек подписи

- Исправлено открытие окна «Подпись по разделам»: ID кнопки превышал 16-битное поле `WM_COMMAND` и обрезался Windows.
- ID окна настроек и кнопок сохранения/отмены приведены к диапазону 16 бит.
- Добавлена регрессионная проверка диапазона и уникальности ID команд.
