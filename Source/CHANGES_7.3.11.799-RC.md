# ROSA 7.3.11.799-RC

- Исправлена видимость страниц при запуске: первоначальная настройка лаборатории больше не может показать её поля поверх Главной.
- Правило владения элементом применяется в точке физического изменения его видимости; позднее обновление неактивной страницы не показывает её элементы.
- Перед первым открытием Главной все зарегистрированные страницы однократно приводятся в скрытое состояние. Переключения после запуска сохраняют быстрый путь только через исходную и целевую страницы.
- Добавлены проверки поведения при отсутствии активной страницы, переключении между страницами и первоначальной инициализации лаборатории.
- Данные 20 скважин, 60 отказов, 180 лабораторных паспортов и 180 экономических сценариев сохранены; логика миграции 798-RC остаётся в составе.
- Нативный GUI запуск на Windows требуется для окончательного подтверждения визуального поведения: среда сборки исполняет переносимые тесты и компилирует Windows приложение и тесты.
