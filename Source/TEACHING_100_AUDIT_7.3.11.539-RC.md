# Аудит 100 встроенных учебных примеров — РОСА 7.3.11.539-RC

Проверка выполнена по исходным XLSX из `demo_examples` без изменения лабораторных измерений.

- Проверено файлов: 100.
- Файлов, где по текущим программным критериям есть хотя бы один назначаемый предварительный класс: 100 из 100.
- Распределение по числу одновременно назначаемых классов: 1 класс(а): 36 файлов; 2 класс(а): 50 файлов; 3 класс(а): 13 файлов; 4 класс(а): 1 файлов.
- Состояние «все направления = НД» для открытого заполненного учебного примера не объясняется пустыми XLSX; оно связано с выбором/закреплением объекта и источника лабораторной записи.
- В RC539 каждый встроенный пример изолируется отдельным ключом `Учебный пример NNN · <исходный объект>`, чтобы состояния классов, методов, МРП и экономики не смешивались между примерами.
- Для шагов МРП и экономики RC539 добавляет только явно помеченный синтетический учебный контекст. Он не считается промысловым фактом и не подтверждает экспертные решения.
