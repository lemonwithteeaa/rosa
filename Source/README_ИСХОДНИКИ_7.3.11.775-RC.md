# Исходники РОСА 7.3.11.775-RC

Архив содержит полный текущий каталог `Исходники`, включая исходный код, QA-скрипты, ресурсы сборки, вспомогательные данные и каталог `.git` с локальной историей.

История начинается с базового импорта 7.3.11.744-RC и содержит теги до 7.3.11.764-RC. Текущие файлы RC775 включены в архив; отдельный коммит и тег RC775 не создавались.

Для сборки Windows x64 из каталога `Исходники` используйте `python3 build_release.py` на Linux с Go в PATH. Скрипт выполняет полный QA-контур и кросс-сборку; для проверки окон, переключения страниц и DPI нужен запуск на Windows.

Сопутствующий готовый EXE, Windows-тестовый бинарник, отчёт и контрольные суммы находятся в полном комплекте RC775 рядом с этим архивом.
