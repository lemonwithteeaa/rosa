# РОСА 7.3.11.824-RC

База: 823-RC. Изменения только интерфейса увеличенного просмотра графиков раздела 5 «Наработка и отказы».

- Легенда распределения справа: четыре элемента сгруппированы в центрированный вертикальный список, а не растянуты на всю высоту панели; обозначение и текст выравниваются по одной горизонтали. Высота многострочного текста рассчитывается перед отрисовкой.
- Названия осей вынесены в отдельные поля: «Наработка, сут.» или «События, шт.» рядом с левой вертикальной шкалой; «Период, мес.» либо «Способы эксплуатации» по центру под осью X. Для подписей используется меньший контрастный шрифт.
- Верхняя строка увеличенного окна: заголовок слева, масштаб и закрытие — справа. Вторая строка: только настройка шага оси Y. Кнопка закрытия не пересекается с другими элементами.
- Первичная раскладка выполняется при создании окна; при изменении размера элементы перестраиваются тем же механизмом.

Расчётные формулы, сохранённые данные и учебный корпус не менялись. Визуальный прогон на целевом Windows обязателен.
